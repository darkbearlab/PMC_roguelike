# 設定聖經（節錄）

> 這份檔案是**專案端的節錄**，不是完整的世界觀文件。
> 完整版在作者手上；這裡只記錄那些**已經變成程式碼約束**的條目 ——
> 也就是實作時必須查得到、否則會寫錯的部分。
>
> 每一條後面都註明它管住了哪一段實作。

## 1. 文體（管住 `data/contracts.json`）

> **用最無趣的公文語言，講最荒謬的事。不要吐槽，不要眨眼，不要讓文字知道自己好笑。**

- 會計與稽核語言優先：資產減損、繼續經營、期後事項、內部控制
- 人命一律以財產語彙表達
- 公文格式要正確：旨、說明、辦法、附件
- **絕不解釋笑點**

主線與所有的角色感都由**合約簡報、公文與服役紀錄**承擔，不做過場動畫。

## 2. 子彈比人貴（管住 §8 的整組數值）

複製人可以再長，彈藥不能。這一句話是彈藥、負重、屍體回收三個系統的共同前提，
也是「這一發值不值得」為什麼是每次開槍都要問的問題。

## 3. 醫療不是治療，是更換（管住 `SEALANT`）

這個時代受了重傷就換一具身體。戰場上的封合劑只是權宜之計，讓你撐完這趟 ——
這也順帶解釋了為什麼它永遠治不好（恢復必須慢、必須不完全、必須稀有）。

## 4. 槍的總數固定，而且只會減少（v0.15 附錄 A）

**精密製造隨企業撤走了。因此這顆星球上的每一把槍，都是撤離之前製造的。**

推論：

- **槍不會被生產，只會流通。**拾荒者把死者身上的東西撿走、重新洗回市場，
  不是遊戲機制，是這個世界唯一的物流方式。
- **稀有度自我解釋**：好槍稀有不是因為掉落率，是因為世界上就剩那幾把。
- **天然的消耗閥**：被摧毀的槍永遠沒了，全世界的總數緩慢減少。
  這比人為的耐久度更符合調性，而且發生在**世界層級**而非玩家層級。

管住的實作：`core/weapon.ts` 的武器實例（`instanceId`、`affixes`、`provenance`）。
一把槍必須是一個實例而不是型號引用，否則上面每一條都無法成立 ——
沒有東西可以被追蹤、被標記、被賦予來歷。

`provenance.actor` **只存公司或勢力名稱，不得存放帳號或使用者識別。**
這是日後開放多人時的隱私邊界。
