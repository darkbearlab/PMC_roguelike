# 設定聖經（節錄）

> 這份檔案是**專案端的節錄**，不是完整的世界觀文件。
> 完整版在作者手上；這裡只記錄那些**已經變成程式碼約束**的條目 ——
> 也就是實作時必須查得到、否則會寫錯的部分。
>
> 每一條後面都註明它管住了哪一段實作。

## 1. 文體（管住 `data/contracts.json`）

> **用最無趣的公文語言，講最荒謬的事。不要吐槽，不要眨眼，不要讓文字知道自己好笑。**

- 會計與稽核語言優先：資產減損、繼續經營、期後事項、內部控制
- 人命一律以財產語彙表達
- 公文格式要正確：旨、說明、辦法、附件
- **絕不解釋笑點**

主線與所有的角色感都由**合約簡報、公文與服役紀錄**承擔，不做過場動畫。

## 2. 子彈比人貴（管住 §8 的整組數值）

複製人可以再長，彈藥不能。這一句話是彈藥、負重、屍體回收三個系統的共同前提，
也是「這一發值不值得」為什麼是每次開槍都要問的問題。

## 3. 醫療不是治療，是更換（管住 `SEALANT`）

這個時代受了重傷就換一具身體。戰場上的封合劑只是權宜之計，讓你撐完這趟 ——
這也順帶解釋了為什麼它永遠治不好（恢復必須慢、必須不完全、必須稀有）。

## 4. 武器分兩層（v0.15 附錄 B 更正）

> **附錄 A 原本寫「這顆星球上的每一把槍都是撤離之前製造的，總數固定且只會減少」。
> 那句話推論過頭了** —— 若所有槍都不可補充，這顆星球上早該沒有槍了，
> 但設定上到處都是武裝勢力。正確的版本是：

> **撤離帶走的是精密製造，不是一切製造。**
>
> **簡易槍械與大部分彈藥仍然可以在本地生產與維護；精密武器不行。**

| | 遺產武器 | 土製武器 |
|---|---|---|
| 來源 | 撤離前製造 | 現在仍可生產 |
| 補充 | **不可能** | 可以 |
| 經濟性質 | 不可替代的資本 | 消耗品 |
| 現有對應 | AR-9、DMR-7、LMG-5、RR-4 | 拉栓手槍與步槍、削短霰彈槍等 |
| 典型形制 | 半自動、自動、精密光學、氣動機構 | 拉栓、中折、單發 |

推論：

- **遺產武器的總數固定且只會減少；土製武器不會。**
- **稀有度自我解釋**：好槍稀有不是因為掉落率，是因為世界上就剩那幾把。
- **大部分在場上廝殺的複製人，手上拿的其實都是土製槍。**
  曾經如此進步的科技，最後留在戰場上的是拉栓與中折。

### 4.1 彈藥同樣分層

| 彈藥 | 本地生產 |
|---|---|
| 12 號徑、粗製手槍彈 | 容易 |
| 5.56、7.62（需穩定膛壓） | 困難但可行 |
| **84mm 火箭彈** | **不可能，屬遺產彈藥** |

**RR-4 是一個會耗盡的資產 —— 每開一砲，世界上就永遠少一發。**
玩家換用重武器的理由因此不只是「快」，而是「那一發用掉就沒了」。
本版不為此加任何機制，日後經濟層據此設計。

（資料上記在 `rules.json` 的 `calibres[].localProduction`，v0.15 不參與任何判斷。）

### 4.2 為什麼武器要做成實例

管住的實作：`core/weapon.ts` 的武器實例（`instanceId`、`affixes`、`provenance`）。
一把遺產槍必須是一個實例而不是型號引用，否則上面每一條都無法成立 ——
沒有東西可以被追蹤、被標記、被賦予來歷。

拾荒者把死者身上的東西撿走、重新洗回市場，不是遊戲機制，
是這個世界唯一的物流方式 —— 至少對遺產武器而言是這樣。

`provenance.actor` **只存公司或勢力名稱，不得存放帳號或使用者識別。**
這是日後開放多人時的隱私邊界。

### 4.3 粗糙是一種能力

土製武器不是「比較爛的槍」。破爛的中折式沒有複雜機構可以被打壞，
所以**能塞任何東西進去**；泵動槍的抽殼機構會被鋼索切段毀掉。

因此最爛的槍會有最寬的彈藥相容性 —— 那是土製武器存在的意義。
（資料上預留在 `WeaponType.action` 與 `AmmoType.allowedActions`，v0.15 不參與判斷。）
